# Plano: gerenciamento de tarefas

1. Definir o modelo de domínio da tarefa e os status válidos (`open`, `done`).
2. Implementar o armazenamento em memória e a camada de serviço com regras de negócio.
3. Expor rotas HTTP para criar, listar, consultar, concluir e remover tarefas.
4. Implementar a CLI para consumir a API HTTP.
5. Cobrir a lógica com testes de serviço e integração HTTP.
6. Validar com `npm test` e `npm run typecheck`.
